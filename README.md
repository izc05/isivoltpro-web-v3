# IsiVoltPro Web V3

Reinicio limpio de la web comercial de IsiVoltPro.

## Regla de desarrollo

Una fase → build → publicación → revisión → aprobación → siguiente fase.

## Fases

- Fase 0 · Foundation + GitHub Pages
- Fase 1 · Portada premium
- Fase 2 · Hero con vídeo
- Fase 3 · Qué es IsiVoltPro
- Fase 4 · Flujo operativo
- Fase 5 · Ecosistema
- Fase 6 · Aplicaciones
- Fase 7 · Sectores
- Fase 8 · CTA + Footer
- Fase 9 · Responsive
- Fase 10 · Motion/polish
- Fase 11 · SEO/rendimiento
- Fase 12 · Publicación definitiva

## Principios

- Sin herencia de V2.
- Sin recursos visuales ficticios presentados como producto real.
- Sin Base64 de vídeo ni reconstrucciones de binarios en CI.
- Motion solo después de aprobar el diseño estático.
