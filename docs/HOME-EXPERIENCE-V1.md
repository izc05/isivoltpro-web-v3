# IsiVoltPro Home Experience V1

## Dirección visual

La Home V3 evoluciona de una sucesión de bloques convencionales a una experiencia continua inspirada en webs editoriales 3D premium.

Referencia conceptual: Lusion y experiencias WebGL/editoriales similares.

No se copia código, recursos, textos ni composición exacta de terceros. Se reutilizan principios de diseño:

- escena visual protagonista;
- tipografía de gran formato;
- fondo negro/grafito;
- retícula técnica;
- scroll narrativo;
- profundidad y capas;
- microanimación controlada;
- transiciones entre secciones sin ruptura visual.
