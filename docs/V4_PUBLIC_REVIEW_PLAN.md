# IsiVoltPro V4 — revisión pública pantalla por pantalla

## Objetivo

Convertir la web pública de IsiVoltPro en una web comercial de alto nivel para vender y promocionar aplicaciones, servicios y conocimiento técnico, sustituyendo recursos visuales genéricos por fotografía realista vinculada al mantenimiento y reforzando copy, CTA, confianza, SEO, responsive y rendimiento.

## Método por pantalla

Cada página se revisa con la misma lista:

1. Qué debe entender un visitante en 5–10 segundos.
2. CTA principal y CTA secundaria.
3. Fotografía o visual principal adecuado al contexto.
4. Captura/UI conceptual solo cuando ayuda a entender el producto.
5. Datos demo claramente identificados como ficticios.
6. Pruebas en 360/390/430 px, tablet y escritorio.
7. Accesibilidad: alt text, foco, contraste y reduced motion.
8. SEO: title, description, intención de búsqueda y enlaces internos.
9. Peso de imágenes y Core Web Vitals.
10. Coherencia visual con el resto de la marca.

## Línea visual

- Fotografía hiperrealista, limpia y creíble, evitando el aspecto de banco de imágenes genérico.
- Técnicos realizando mantenimiento real de climatización, cuadros eléctricos, bombas, ACS, fontanería, instalaciones, inspecciones y trabajo de campo.
- Uso de móvil o tablet cuando tenga relación directa con IsiVoltPro.
- Uniformes sobrios y coherentes en toda la serie.
- Salas técnicas, talleres, comercios, edificios e industria ligera como escenarios principales.
- Espacio negativo deliberado para copy y CTA.
- Color y contraste homogéneos en todas las imágenes.
- No asociar instalaciones o técnicos ficticios a clientes reales.

## Primer mapa fotográfico

### Home
- Mantener la entrada de marca como experiencia diferenciadora.
- Sustituir el SVG conceptual del técnico móvil por fotografía real de técnico usando móvil/tablet junto a un activo.
- Añadir una escena real de mantenimiento en el bloque de módulos o de resultados, sin competir con el dashboard principal.

### Producto
- Mantener el dashboard V4 como explicación funcional.
- Añadir una fotografía editorial de técnico en sala técnica para conectar software con trabajo real.
- Segunda imagen recomendada: técnico escaneando QR/NFC de un activo.

### App Mantenimiento
- Esta página es el mejor destino para la imagen de técnico escaneando un equipo con móvil.
- La fotografía debe convivir con la UI móvil de IsiVoltPro, no sustituirla por completo.

### Soluciones
- Usar fotografía de dos técnicos revisando información en tablet o una escena de intervención con contexto compartido.
- El hero debe seguir explicando el problema; la foto debe demostrar el mundo real que hay detrás.
