# Identidad IsiVoltPro V4

Identidad aprobada para la evolución V4 de IsiVoltPro.

- Símbolo: marco hexagonal abierto con rayo central.
- Paleta: cian, azul eléctrico, violeta y azul marino profundo.
- Wordmark: `IsiVolt` en azul marino y `Pro` en degradado azul-violeta.
- `isivoltpro-mark-v4.svg` es el símbolo maestro para web, favicon y superficies escalables.
- El componente `V3Brand.astro` es la fuente única para cabecera, pie e interfaces compartidas.
- `site.webmanifest` mantiene la misma identidad para instalación desde navegador.

No crear variantes nuevas del símbolo dentro de componentes o páginas. Cualquier evolución futura debe partir de estos masters.
